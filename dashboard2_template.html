Data: blockchain.info (BTC price), alternative.me (Fear & Greed Index). This composite blends 50-day MA distance, 5-day-smoothed Fear & Greed, daily RSI(14), Bollinger %B(20), and MACD histogram (12/26/9) into one 0-100 score, tuned for roughly 8-10 repositioning signals a year. It's a practical technicals-based tool, not a separately back-tested edge like the long-term dashboard — earlier testing found these short-lookback indicators tend to confirm trend rather than call reversals (see the repo README for that finding in full). Use it for sizing partial trims/adds, not as a standalone reason to trade. Not financial advice — run st_current_status.py for a live check.
