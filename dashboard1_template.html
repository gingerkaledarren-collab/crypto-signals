Data: blockchain.info (BTC price), Fear & Greed Index blended from alternative.me (history before ~June 2023) and CoinMarketCap (from that point forward). Composite = equal-weighted 200-week MA distance, 7d-smoothed Fear & Greed, weekly RSI, and Pi Cycle Top ratio, each normalized 0–100. The 7-day smoothing window is an experimental variant being tried on this page only — walk-forward testing found the validated 30-day window produces a meaningfully stronger out-of-sample signal (10.3pp TRAIN spread vs. 7.8pp at 7 days); thresholds/confirmation days below are otherwise unchanged from that 30-day-validated selection (2018–2023 train, tested blind on 2023–2026). The dashed 21w/34w EMA lines (a trader Alessio Rastani-style support structure) are shown for context only — testing found adding them to the composite weakened out-of-sample performance, so they're tracked but not scored; see the README's "Why the EMA structure indicator isn't in the default weighting." Not financial advice — generated from crypto-signals, run current_status.py for a live check (still defaults to 30-day smoothing).
